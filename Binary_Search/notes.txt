//  # Binary Search
//
//  ## What is Binary Search?
//
//  Binary Search is a searching algorithm that works by repeatedly
//  dividing a sorted search space into half.
//
//  ## Intuition
//
//  Instead of checking every element one by one, we eliminate half
//  of the possible answers after every comparison.
//
//  ## When can I use it?
//
//  - The array is sorted
//  - Or the search space has a monotonic property
//  - We can determine which half can be eliminated
//
//  ## Time Complexity
//
//  O(log n)
//
//  ## Space Complexity
//
//  O(1)
//
//  ## Common Mistakes
//
//  - Incorrectly updating low/high
//  - Using the wrong loop condition
//  - Calculating mid unsafely
//
//  ## Problems I Solved
//
//  - Search in Rotated Sorted Array
//  - Find First and Last Position
//  - Binary Search
//
